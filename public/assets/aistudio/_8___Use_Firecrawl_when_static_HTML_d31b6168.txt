name: Vitest runtime compatibility
description: The current mismatch between this workspace's Node runtime and Vitest 5.
---
As of 2026-11-03, the workspace runs Node 20 while its Vitest 5 version expects Node 22 or newer. A test failure under Node 20 can make Vitest's reporter crash on `Map.groupBy`, obscuring the original assertion.
**Why:** The package manager reports the unsupported engine, and an observed test failure triggered the separate reporter exception.
**How to apply:** When tests fail under the current runtime, first distinguish test assertions from reporter failures. Prefer running Vitest under a supported Node version; use a temporary compatibility shim only for verification, not as an application change.

    status: attemptedUrls.length > 0 && unavailableUrls.length === attemptedUrls.length ? 'unavailable' : 'measured',
    attemptedUrls,
    evidence,
    unavailableUrls,
    ...(lastReason ? { reason: lastReason } : {})
  };
